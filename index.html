Le Repo Du Jour Studio

Le Repo Du Jour Studio is a small desktop tool used by the creator of the French-language channel « Le Repo Du Jour » (one open-source GitHub project explained every day in a short vertical video).

What it does
  • Shows the creator the day's prepared video, its script and its caption.
  • After the creator has watched and approved the video, it uploads it to the creator's own TikTok account through the official TikTok Content Posting API (and to YouTube through the YouTube Data API).
  • Nothing is ever posted without the creator's explicit approval in the app.
Who can use it

Only the channel owner. The tool runs locally on the owner's computer; there is no public sign-up and no other users.

Version française : Le Repo Du Jour Studio est l'outil personnel du créateur de la chaîne « Le Repo Du Jour ». Il publie sur son propre compte TikTok, uniquement après sa validation.
